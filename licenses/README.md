# Licenses and provenance

`pi-stardeck` is private and currently marked `UNLICENSED` as a whole. Imported
third-party-derived components retain their own licenses:

- `pi-vim-LICENSE` covers the imported `pi-vim-top-border` descendant.

The same license text remains beside each imported source. Local modifications are
recorded in:

- `packages/pi-vim-top-border/LOCAL-CHANGES.md`.

The former Fancy Footer fork was replaced by the clean-room
`packages/footer` telemetry provider (see
`openspec/changes/replace-fancy-footer-with-stardeck-footer`); its license and
local-change records were removed with it. Do not remove or replace the
remaining notices when consolidating or packing the source. A future public
release requires an explicit project-level licensing decision in addition to
retaining upstream attribution.
